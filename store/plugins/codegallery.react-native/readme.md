# React Native Tools

React Native snippets (components, hooks, StyleSheet, FlatList, navigation) and terminal commands. Auto-complete for JS/TS comes from the built-in TypeScript server. Building the app needs a computer or Expo.

## How to use

Command Palette > "React Native Tools" for snippets and commands.

## Commands

- React Native Tools: Insert snippet (functional component, useState, useEffect, FlatList, TouchableOpacity button, StyleSheet, TextInput, React Navigation stack)
- React Native Tools: npm install

Made by Code Gallery.
