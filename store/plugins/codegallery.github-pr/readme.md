# GitHub Pull Requests

Work with GitHub pull requests: list, view, see the diff, checkout, comment, approve, merge, and create new PRs (GitHub CLI).

## How to use

Run "GitHub Pull Requests: Login to GitHub" once, then open a file in your repo and use "Pull requests".

## Commands

- GitHub Pull Requests: Pull requests
- GitHub Pull Requests: Create pull request
- GitHub Pull Requests: Login to GitHub
