# JavaScript Snippets

Ready-made JavaScript: functions, async fetch, DOM events, classes, array helpers, debounce, localStorage, Node server.

## How to use

1. Open a file.
2. Open the Command Palette (menu or Ctrl+Shift+P).
3. Search **JavaScript Snippets** and pick a snippet. It is inserted at the cursor.
