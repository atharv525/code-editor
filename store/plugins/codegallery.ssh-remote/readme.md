# SSH Remote

Save SSH servers and connect in the terminal, create an SSH key, upload the current file (scp), sync your project folder to the server (rsync). Edit remote files with the built-in SFTP folder.

## How to use

Command Palette > "SSH Remote: Connect" and add your server.

## Commands

- SSH Remote: Connect (terminal)
- SSH Remote: Create / show SSH key
- SSH Remote: Upload current file (scp)
- SSH Remote: Sync folder to server (rsync)
- SSH Remote: Edit remote files (SFTP)
