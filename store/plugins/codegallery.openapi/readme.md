# OpenAPI (Swagger) Editor

Write OpenAPI / Swagger specs with YAML language server (auto-complete and validation from the OpenAPI schema), snippets, and a live Swagger UI preview.

## How to use

Open your openapi.yaml, then Command Palette > "OpenAPI (Swagger) Editor: Preview API docs". Preview needs internet.

## Commands

- OpenAPI (Swagger) Editor: Insert snippet (OpenAPI 3 starter, Path (GET + POST), Schema object, Bearer auth)
- OpenAPI (Swagger) Editor: Preview API docs

Language server installs in the terminal the first time you open a matching file (needs internet). Manage it in Settings > Language servers.
