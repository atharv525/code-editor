# JS Debugger

Debug JavaScript with the Node.js inspector in the terminal: breakpoints (debugger; or sb(line)), step over/in/out, watch and inspect variables in repl. Also run the current file with Node.

## How to use

Open a .js file, then Command Palette > "JS Debugger: Debug current file". Commands: c continue, n next, s step in, o step out, repl to inspect.

## Commands

- JS Debugger: Debug current file (Node inspector)
- JS Debugger: Run current file (Node)
