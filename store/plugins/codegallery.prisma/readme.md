# Prisma

Prisma schema support: highlighting for .prisma files, official Prisma language server (auto-complete, errors, formatting) and model snippets. Terminal commands for prisma generate / migrate.

## How to use

Open schema.prisma. Use Command Palette > "Prisma" for snippets, generate and migrate (runs in your project folder).

## Commands

- Prisma: Insert snippet (schema starter (SQLite), model, relation (one-to-many), enum)
- Prisma: Generate client
- Prisma: Migrate dev
- Prisma: Open Prisma Studio

Language server installs in the terminal the first time you open a matching file (needs internet). Manage it in Settings > Language servers.
