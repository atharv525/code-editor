# Vue

Vue 3 support with the official Vue language server: auto-complete, errors and go to definition in templates, script and style. Plus component snippets.

## How to use

Open a .vue file (run npm install in your project for best results). The server installs once.

## Commands

- Vue: Insert snippet (SFC (script setup), defineProps, defineEmits, computed, watch, v-for, onMounted)

Language server installs in the terminal the first time you open a matching file (needs internet). Manage it in Settings > Language servers.
