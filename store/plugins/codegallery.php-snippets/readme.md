# PHP Snippets

Ready-made PHP code: page template, functions, classes, forms, PDO database, JSON API, sessions.

## How to use

1. Open a file.
2. Open the Command Palette (menu or Ctrl+Shift+P).
3. Search **PHP Snippets** and pick a snippet. It is inserted at the cursor.

## Snippets

- PHP page
- Function
- Class
- foreach
- Form POST handler
- PDO SQLite connect
- JSON API response
- Session start
- try / catch
