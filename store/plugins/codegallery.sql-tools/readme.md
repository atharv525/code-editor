# SQL Tools

Connect to SQLite, MySQL/MariaDB and PostgreSQL. Save connections, browse tables and run the SQL statement under the cursor (or the selection) from any .sql file.

## How to use

"SQL Tools: Add connection", then in a .sql file put the cursor in a statement and run "SQL Tools: Run query".

## Commands

- SQL Tools: Insert snippet (SELECT, CREATE TABLE, INSERT, UPDATE, JOIN)
- SQL Tools: Run query (selection or statement)
- SQL Tools: Browse connection
- SQL Tools: Add connection
- SQL Tools: Remove connection
