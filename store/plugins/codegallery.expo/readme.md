# Expo Tools

Expo snippets (app.json, Expo Router screens, layouts) and terminal commands: create app, start dev server with tunnel (scan the QR in Expo Go), install packages. Experimental on phone.

## How to use

Command Palette > "Expo Tools". Start dev server shows a QR code; open it in the Expo Go app.

## Commands

- Expo Tools: Insert snippet (app.json, Expo Router screen, Expo Router layout (Stack), Tabs layout)
- Expo Tools: Create Expo app
- Expo Tools: Start dev server (tunnel)
- Expo Tools: Install package
