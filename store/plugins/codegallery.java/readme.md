# Java

Java support with Eclipse JDT Language Server: auto-complete, errors, imports, refactoring. Installs OpenJDK (large download, first time only).

## How to use

1. Install this plugin.
2. Open a .java file.
3. The first time, Code Editor asks to install the language server in the terminal (needs internet).
4. You get auto-complete, errors and go to definition.

Manage it in Settings > Language servers.
