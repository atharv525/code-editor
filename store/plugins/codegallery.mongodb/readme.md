# MongoDB

MongoDB snippets (Node driver, Mongoose models, queries, aggregation) and MongoDB Shell (mongosh) in the terminal: connect with your connection string (Atlas works).

## How to use

Command Palette > "MongoDB: Connect (mongosh)" and paste your mongodb+srv:// connection string.

## Commands

- MongoDB: Insert snippet (Node driver: connect, Mongoose: connect, Mongoose: model, find, insertOne, updateOne, aggregate, mongosh playground)
- MongoDB: Connect (mongosh)
- MongoDB: Run current .js in mongosh
