# GraphQL

GraphQL syntax highlighting (.graphql, .gql), language server (auto-complete and validation from your schema via graphql.config) and snippets.

## How to use

Open a .graphql file. For schema-aware auto-complete add a graphql.config.yml with schema: ./schema.graphql in your project folder.

## Commands

- GraphQL: Insert snippet (query, mutation, type, input, enum, fragment, graphql.config.yml)

Language server installs in the terminal the first time you open a matching file (needs internet). Manage it in Settings > Language servers.
