# CSS Snippets

Ready-made CSS: reset, flexbox center, grid layout, media query, variables, animation, card, button, dark mode.

## How to use

1. Open a file.
2. Open the Command Palette (menu or Ctrl+Shift+P).
3. Search **CSS Snippets** and pick a snippet. It is inserted at the cursor.

## Snippets

- Modern reset
- Flex center
- Responsive grid
- Media query (mobile)
- CSS variables
- Keyframe animation
- Card
- Button
- Dark mode
