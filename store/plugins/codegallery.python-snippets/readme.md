# Python Snippets

Ready-made Python code: main block, functions, classes, loops, file I/O, try/except, dataclass, argparse.

## How to use

1. Open a file.
2. Open the Command Palette (menu or Ctrl+Shift+P).
3. Search **Python Snippets** and pick a snippet. It is inserted at the cursor.
