# Docker

Dockerfile language server and snippets, plus control a Docker server over SSH: containers (logs, shell, restart, stop), images, compose up/down, build. Containers cannot run on the phone itself.

## How to use

Set your server once with "Docker: Set Docker server (SSH)" (ssh://user@host, key login recommended: SSH Remote > Create key).

## Commands

- Docker: Insert snippet (Dockerfile (Node), Dockerfile (Python), docker-compose.yml, .dockerignore)
- Docker: Containers
- Docker: Images
- Docker: Compose up (current folder)
- Docker: Compose down
- Docker: Build image (current folder)
- Docker: Set Docker server (SSH)

Language server installs in the terminal the first time you open a matching file (needs internet). Manage it in Settings > Language servers.
