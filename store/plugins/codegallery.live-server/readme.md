# Live Server

Serve your project at http://127.0.0.1:5500 with live reload: every save refreshes the page in the in-app browser.

## How to use

Open your project folder (or an .html file), then Command Palette > "Live Server: Start". First start downloads live-server (needs internet).

## Commands

- Live Server: Start (open in browser)
- Live Server: Stop
