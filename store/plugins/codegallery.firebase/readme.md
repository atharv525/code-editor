# Firebase

Firebase snippets (init, Auth, Firestore CRUD, Storage, security rules) and Firebase CLI commands in the terminal: login, init, deploy, emulators.

## How to use

Command Palette > "Firebase". For CLI login choose the link shown in the terminal (uses --no-localhost).

## Commands

- Firebase: Insert snippet (initialize app (web), Auth: email sign in, Auth: Google sign in, Firestore: add doc, Firestore: get docs, Firestore: realtime listener, Firestore: update / delete, Storage: upload file, firestore.rules)
- Firebase: CLI login
- Firebase: firebase init
- Firebase: firebase deploy
