# Angular Language Service

Angular template intelligence with the official Angular language server: auto-complete, errors and go to definition in templates. Experimental on phone (needs your project's node_modules for best results). Plus component and service snippets.

## How to use

Open your Angular project folder (run npm install in it first), then open a component .html or .ts file.

## Commands

- Angular Language Service: Insert snippet (standalone component, service, signal, @for, @if, route)

Language server installs in the terminal the first time you open a matching file (needs internet). Manage it in Settings > Language servers.
