# REST Book

Send HTTP requests from .http / .rest files and see the response in a new tab, like REST Client / REST Book. Variables with @name = value and {{name}}. Separate requests with ###.

## How to use

Create a file like api.http, write a request (GET https://api.github.com), put the cursor on it, then Command Palette > "REST Book: Send request".

## Commands

- REST Book: Insert snippet (GET request, POST JSON, PUT JSON, DELETE request, Bearer token header, Variable)
- REST Book: Send request
