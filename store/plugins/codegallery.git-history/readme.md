# Git History

Git inside the editor: inline blame on the current line (who changed it and when), commit details, file history with diffs, and Source Control page to commit, push and pull.

## How to use

Open a file in a Git repository. Inline blame appears at the end of the line. Command Palette > "Git History" for the rest.

## Commands

- Git History: Source Control (status, commit, push, pull)
- Git History: Blame current line (show commit)
- Git History: File history
- Git History: Toggle inline blame
- Git History: Init repository
