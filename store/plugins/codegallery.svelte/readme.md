# Svelte for VS Code

Svelte support: .svelte highlighting, the official Svelte language server (auto-complete, errors, go to definition in markup, script and style) and component snippets.

## How to use

Open a .svelte file. The language server installs once (needs internet).

## Commands

- Svelte for VS Code: Insert snippet (component (Svelte 5), each block, if block, await block, $derived, $effect, SvelteKit load (+page.js))

Language server installs in the terminal the first time you open a matching file (needs internet). Manage it in Settings > Language servers.
