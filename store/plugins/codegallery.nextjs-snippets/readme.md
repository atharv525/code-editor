# Next.js Snippets

Ready-made Next.js (App Router) code: page, layout, client component, API route, server action, loading, metadata.

## How to use

1. Open a file.
2. Open the Command Palette (menu or Ctrl+Shift+P).
3. Search **Next.js Snippets** and pick a snippet. It is inserted at the cursor.

## Snippets

- Page (app/page.tsx)
- Layout (app/layout.tsx)
- Client component with state
- API route (app/api/route.ts)
- Server component fetch
- Server action
- Dynamic route params
- loading.tsx
- Link and Image
